## Research & Embedded

<details open>
<summary><b>Chest X-Ray Disease Classification (97.57% Accuracy)</b></summary>
<br/>

> **4-class classification framework** (COVID-19, Pneumonia, Tuberculosis, Normal) using Wavelet Denoising, Xception and CBAM Attention. Achieved **97.57% accuracy** and **Macro F1: 0.9697**, quantised to TensorFlow Lite for edge deployment on **Raspberry Pi**.

`Python` `TensorFlow Lite` `Xception` `CBAM` `Raspberry Pi` `Edge AI`
</details>

<details open>
<summary><b>Explainable Ocular Disease Diagnosis (91.6% Accuracy)</b></summary>
<br/>

> An **Explainable AI (XAI)** framework using **EfficientNet-B3** with **Grad-CAM**, **SHAP** and **LIME**. Attained **91.6% accuracy** while generating clinically interpretable visual explanations. Browser version: **[ocular-ai](https://github.com/SRJ-ai/ocular-ai)** runs the model client-side in TensorFlow.js.

`Python` `EfficientNet-B3` `Grad-CAM` `SHAP` `LIME` `TensorFlow.js`
</details>

<details open>
<summary><b>PALS-QTPL Real-Time Digital Notice Board — ₹80,000 Funded</b></summary>
<br/>

> **₹80,000 innovation grant** supported by PALS, IIT Madras & IIT Hyderabad. An ESP8266-based industrial comms platform with MQTT & Flask driving P10 LED panels. Cut deployment costs by **>80%** against commercial signage, held **sub-250ms** latency and ran **>72 hours** uninterrupted. Published in **IJFMR**.
>
> *DOI: [10.36948/IJFMR.2026.V08I02.74943](https://doi.org/10.36948/IJFMR.2026.V08I02.74943)*

`ESP8266` `MQTT` `Flask` `P10 LED` `IoT` `Published Research`
</details>

<details>
<summary><b>Oral Cancer Detection using Deep Learning</b></summary>
<br/>

> Classification pipelines leveraging **VGG19**, **MobileNetV2** and **Vision Transformers (ViT)**, with transfer learning, hyperparameter optimisation and custom attention. Validated on ROC-AUC, F1, confusion matrices and Grad-CAM.

`Python` `TensorFlow` `Vision Transformers` `Grad-CAM` `Transfer Learning`
</details>

<details>
<summary><b>Touchless HCI — gesture-controlled interface</b></summary>
<br/>

> Real-time touchless human-computer interaction on **Jetson Nano** using **MediaPipe** hand-gesture recognition for media and cursor control.

`Python` `OpenCV` `MediaPipe` `Jetson Nano` `HCI`
